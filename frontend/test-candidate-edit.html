COMPSA Candidate Name Editing Feature

New Feature - Candidate Name Editing

How to Test the New Feature:

  1. Click on the "COMPSA Committee" link below
  2. On the committee page, you'll see three new buttons:
    • "Edit Position Names" - for nomination form positions
    • "Edit Voting Position Names" - for voting form positions
    • "Edit Candidate Names" - for candidate names in the voting form
  3. Click the "Edit Candidate Names" button to rename the candidates
  4. You'll be prompted to enter new names for each candidate
  5. After renaming, the voting form will update with your new candidate names

✅ New Edit Functionality

We've added the ability to customize candidate names:

  • Edit candidate names in the voting form
  • Changes persist using browser localStorage
  • Simple prompt-based interface for easy editing
  • Works in conjunction with position renaming features
